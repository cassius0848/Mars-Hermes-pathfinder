# 已验证的局部数据包

所有地理坐标均指火星，北纬为正、东经为正。GeoTIFF 内嵌火星 CRS 和仿射变换。`jezero-route-preview.json` 使用带显式火星坐标说明的 JSON，供本项目读取。

在含 Python、NumPy、SciPy、Matplotlib、Pillow、Rasterio、PyProj 和 Shapely 2.1+ 的环境中，从本目录运行 `python prepare_context.py` 与 `python verify_site.py`。联网时可用 `python crop_sources.py dtm ortho thermal` 重新从 USGS COG 读取同一裁片。预览算法独立于仓库，供核对数据和方案。`sha256.txt` 记录包内数据、脚本和文档的完整性校验值。
